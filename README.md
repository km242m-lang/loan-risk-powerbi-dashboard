# Loan Risk Analysis Dashboard (Power BI)

Analyzes customer demographics, loan performance and default risk for a ₹252.6M loan portfolio.

## Dashboard Pages
1. *Customer Demographics:* 3,134 customers, average age 44, average income ₹99,269
2. *Loan Portfolio & Performance:* loan mix by type and status, average interest rate 8.97%
3. *Financial Risk Analysis:* 519 defaulted loans (₹26.19M), 2,547 high-risk loans (₹127.97M)

## Key Insights
- About 51% of the portfolio by value is high risk
- Full-time borrowers have the most defaults (143), unemployed the fewest (116)
- Credit scores and loan amounts are spread evenly across groups and loan types

## Tools Used
Power BI, DAX, Excel
